 **[Python Security Automation Script](./file_automation.ipynb):** An interactive Jupyter Notebook automating access control lists (ACLs) by parsing corporate IP files to update security allow-lists.

- **[SQL Log Forensics & Querying](./sql_queries.txt):** A library of SQL scripts used to query organizational relational databases to identify anomalous login spikes, outside logins, and employee machine updates.

- **Commonwealth Bank Web Application Penetration Testing (Task 4)**: Completed 11 targeted browser-based security labs covering Cross-Site Scripting (XSS), SQL Injection, Path Traversal, and Information Disclosure, accompanied by a formal [Penetration Testing Report PDF](./reports/CBA_Penetration_Testing_Executive_Report.pdf).
